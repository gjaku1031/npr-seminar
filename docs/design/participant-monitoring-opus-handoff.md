# 참가자 모니터링 UI 핸드오프

> Fable `/design` 호출 한도가 소진되어, 사용자 허용에 따라 Opus Max에 같은 브리프를 전달했다. CLI 응답이 중단되어 아래 결정은 제공된 화면 3장과 현재 예시학원 디자인 토큰을 기준으로 고정한다. 새 시각 언어를 만들지 않는다.

## 목적과 집계 언어

- 예약 명단에서는 현재 필터 범위의 실제 참석 규모를 한눈에 확인한다.
- 통계에서는 비율이나 정원 대신 절대 인원 흐름을 비교한다.
- 세 용어는 모든 화면에서 동일하게 쓴다.
  - `해당 학생`: 필터에 걸린 학생·비재원생 행 수
  - `형제원생 제외`: 형제자매를 한 가족 예약으로 합친 수
  - `참가자수`: 예약 상태가 `예약` 또는 `입장 완료`인 가족의 참석 학부모 수. 모·부는 1명, 모/부는 2명

## 예약 명단

- 캠퍼스 선택 칩 중 현재 선택된 칩만 `전체 | 참가자수 000명`처럼 확장한다. 캠퍼스를 선택하면 `A | 참가자수 000명`처럼 범위를 함께 표시한다.
- 텍스트와 숫자는 한 줄을 유지하고, 가운데 1px 구분선을 둔다. 기존 선택 칩의 녹색 배경·그림자·높이는 유지한다.
- 확장 칩에 마우스를 올리거나 키보드 포커스하면 아래에 236px 내외 팝오버를 연다. 클릭·터치는 팝오버를 고정하며 바깥 클릭과 Esc로 닫는다.
- 팝오버는 기존 카드 토큰(`surface-card`, `border-hairline`, `shadow-float`, `radius-md`)을 그대로 쓴다. 세 행은 36px 이상 높이로 하고 라벨은 왼쪽, 탭 숫자는 오른쪽 정렬한다.
- 팝오버 행은 정확히 `해당 학생`, `형제원생 제외`, `참가자수` 순서다. 선택 캠퍼스와 단위·담임·검색 조건을 모두 반영한 서버 집계를 표시한다.
- API 롤링 배포 중 집계가 없으면 숫자를 임의 계산하지 않고 `—`로 표시한다.

## 운영 통계

- 정원, 예약률, 참석률, 노쇼율, 퍼센트 막대, 도넛 비율은 전부 제거한다.
- 첫 줄은 핵심 3개 카드: `해당 학생`, `형제원생 제외`, `실 참가자`.
- 둘째 줄은 운영 상태 3개 카드: `입장 완료`, `미입장`, `취소`. 단위는 모두 가족 예약 `건`으로 통일한다.
- 하단 좌측은 단위별 표다. 각 행에 단위, 해당 학생, 형제원생 제외, 참가자수를 절대값으로 표시한다. 녹색 배경 강조나 얇은 하이라이트만 사용하고 비율 막대는 쓰지 않는다.
- 하단 우측은 예약 채널 카드다. 모바일·수동 각각 학생/가족/참가자 세 수치를 동일한 작은 격자로 보여준다. 채널 간 비율은 표시하지 않는다.
- 만족도는 기존처럼 평균과 응답 건수만 읽기 전용으로 유지한다.
- 데스크톱은 하단 1.6:1 그리드, 767px 이하는 한 열로 쌓는다. 어떤 폭에서도 페이지 전체 가로 스크롤을 만들지 않는다.

## 접근성과 상태

- 확장 칩은 `aria-expanded`, `aria-controls`, `aria-describedby`를 제공한다.
- 팝오버는 `role=status`가 아닌 설명 보조 콘텐츠로 연결하고, 갱신 때 화면 낭독을 반복하지 않는다.
- 로딩 시 기존 수치를 임의로 0으로 바꾸지 않고 전체 영역 opacity만 낮춘다.
- 숫자는 `font-feature-settings: "tnum"`과 `ko-KR` 천 단위 구분을 사용한다.
