# 늘푸른수학원 브랜드 리스킨 핸드오프 (색·로고 전용)

2026-07 · Fable 선택안. **색과 로고만** 교체하는 리스킨이다. 레이아웃·타이포·간격·radius·정보구조·카피·동작·API·백엔드는 **그대로** 둔다.

레거시 CSS 변수명(`--violet-*`, `--mint-*`, `--ink-*`, `--status-*` 등)은 호환을 위해 **이름을 유지**하고 **값만** 늘푸른 로고 팔레트로 매핑했다. 단일 출처는 `apps/web/src/app/globals.css` 이며, 핸드오프 사본(`docs/design/npr-seminar-handoff/tokens/*.css`)을 동일하게 갱신했다.

## 로고 사용

- 실제 브랜드 자산: **`apps/web/public/brand/neulpureun-logo-source.jpg`** (사용자 제공 원본, 1280×1280 무손실 보존). 초록 나무 블롭 + 흰색 한글 글자 "늘푸른".
- 절대 텍스트·SVG·CSS 아트로 재현하지 않는다. **흰색을 전역 제거하지 않는다** — 흰색이 곧 글자다.
- 재사용 컴포넌트 **`shared/ui/BrandMark`** 가 원본을 정사각 프레임에 `overflow: hidden` 으로 **여백만 클리핑**해 타이트하게 보여준다 (모든 로고 픽셀·내부 흰 글자 보존).
- 접근성 라벨: 기본 alt `늘푸른수학원`. 로고=허브 링크는 `brandHomeLabel()` → **`늘푸른수학원 입시설명회 홈`**. 상위 요소가 이미 이름을 가지면 `decorative` 로 중복 낭독을 피한다.
- 가짜 "npr" 블루 텍스트 배지를 교체한 곳: TopNav, ConsoleShell 허브 헤더, LoginForm, SMS 폰 프리뷰, 공개 모바일 FlowHeader(홈 상태). 인접 "입시설명회" 텍스트는 보존.
- Next 앱 아이콘: `apps/web/src/app/icon.jpg`, `apple-icon.jpg` (원본에서 기계적 복제).

## 시맨틱 규칙

- 프라이머리 버튼·선택된 필터 = **다크 포레스트 + 흰 글자**.
- **성공 지표 = 틸**(브랜드 포레스트 아님). **정보·키보드 포커스 = 블루**. **오류 = 레드**, **경고 = 오렌지**.
- 밝은 로고 색(`#89AF0E #ACCF2A #DAE11F #F9C059 #E06F23`)은 **장식/차트 액센트 전용, 항상 다크 텍스트** — 작은 흰 텍스트 금지.
- 다크 브랜드 표면 위 텍스트 = 흰색. 다크 표면의 의미 있는 흰색 리터럴은 보존.
- danger 버튼 텍스트는 접근성 흰색(기존 다크 텍스트 교체) + 신규 danger 램프.
- 액센트 버튼은 `#006C8B → #007A9B` 위 흰 글자로 고정해 가장 밝은 끝에서도 WCAG AA 대비를 유지한다.

## 스캐너/QR 불변식

- QR 의 리터럴 흑/백 렌더링과 오류정정(EC)은 **변경 금지**.
- 카메라/스캐너 기능 표면은 니어블랙 유지. 스캔 프레임·스캔라인은 **액센트 블루**(`--mint-400 #00ABDB`), 결과는 상태색.

## 의도적으로 보존된 블루/리터럴

- **키보드 포커스 링·정보(info) 상태**는 블루(#006C8B)로 **의도적** 유지 — 이 리스킨에서 유일하게 남는 브랜드 블루다.
- **스캐너 액센트/스캔라인**은 액센트 틸·블루(#008AAA/#00ABDB)로 유지 — 스펙이 명시.
- QR 흑백, 니어블랙 스캐너 표면(`rgba(10,15,26,*)`), 다크 표면의 흰색 리터럴은 의도적으로 보존.
